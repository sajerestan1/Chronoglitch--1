# Chronoglitch history-video production kit

A reusable, beginner-friendly kit for planning and producing history videos with Chronoglitch, your recurring polished 3D narrator.

## Start here

1. Read [the character bible](docs/character-bible.md) and keep [the canonical concept image](assets/character/approved-concept.png) unchanged.
2. Copy the files in `templates/` into a new folder for each episode.
3. Research the topic and record source-backed claims in the fact-check ledger.
4. Freeze the script, then plan the timed visual beats in the scene plan.
5. Check that your chosen tools support the reference images, voice, animation, audio sync, and export you need.
6. Make and review a short proof scene before producing the rest.
7. Use the [production prompt](prompts/production-agent.md) as a guide when an agent is helping.

## What's included

- `assets/character/`: the original supplied image and notes for preserving the design.
- `docs/character-bible.md`: Chronoglitch's identity, appearance and performance guidance.
- `docs/production-workflow.md`: research, planning, production, review and export steps.
- `prompts/`: reusable character-image, scene and production prompts.
- `templates/`: episode brief, fact-check ledger, scene plan and production ledger.

Each episode should have its own copy of the brief, claim ledger, scene plan and production ledger. Keep episode media separate from canonical character references so you can reuse the character without starting over.

## Important limits

This repository is a planning and continuity template. It does not automatically research history, generate speech or video, operate VideoExpress or CloneVoice, or publish content. Check the services' actual features, costs, usage limits and privacy controls before production. A prompt cannot guarantee character consistency or exact lip sync; review the output.

Do not store passwords, API keys or private voice recordings here. Use only a voice you are authorized to use. Keep historical claims tied to credible sources, and label generated reconstructions so they are not mistaken for archival footage. Treat histories of violence and suffering with care.

## Reuse on GitHub

Choose **Use this template → Create a new repository** to start a separate project from these files. The new repository receives the files and folders from the default branch, but not this repository's commit history.
